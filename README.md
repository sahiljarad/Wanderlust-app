# 🌍 WanderLust App

A full-stack web application for listing and exploring travel destinations.

---

## 🚀 Features

- 🏠 Create, edit, and delete listings
- 📍 Add location, country, and price
- 🖼️ Add image URL for listings
- 🔐 User authentication (Login/Register)
- ⭐ Reviews and ratings (optional)
- 📱 Responsive design

---

## 🛠️ Tech Stack

### Frontend
- HTML
- CSS
- Bootstrap
- EJS

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose
